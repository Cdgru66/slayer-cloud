Slayer Fleet Cloud - เซิร์ฟเวอร์กลาง ให้ลูกค้าดูข้อมูลไอดีผ่านเว็บ (มือถือ/คอม)
ทุกอย่างจัดการผ่าน admin.bat มี 2 โหมด (กด M ในเมนูเพื่อสลับ)

อัปเดตเวอร์ชันใหม่: ดับเบิลคลิก update.bat อย่างเดียว
  ดึงไฟล์ล่าสุดจาก GitHub (Cdgru66/slayer-cloud) สำรอง data ไว้ใน backups แล้วเปิดเซิร์ฟเวอร์ใหม่ให้เอง
  repo เป็น private จึงต้องมี token ครั้งแรกครั้งเดียว:
    1. github.com > รูปโปรไฟล์ > Settings > Developer settings > Personal access tokens > Fine-grained tokens > Generate new token
    2. Repository access: Only select repositories > เลือก slayer-cloud
    3. Permissions > Repository permissions > Contents: Read-only  (อย่างเดียวพอ)
    4. Expiration ตั้งได้ตามสะดวก (หมดอายุแล้วทำใหม่) > Generate token > ก๊อป
    5. สร้างไฟล์ data\github_token.txt วาง token ลงไป บันทึก (อยู่ใน data จึงไม่ถูกอัปโหลด/ทับ)
  ถ้าดึงจาก GitHub ไม่ได้ จะใช้ไฟล์ slayer-cloud*.zip ล่าสุดในโฟลเดอร์ Downloads แทน
  สคริปต์ในเกม: ใช้ data\scripts\OWNER-LOADER.lua (3 บรรทัด) ดึงสคริปต์ล่าสุดจากเซิร์ฟเวอร์เองทุกครั้งที่รัน
  (ถ้าลิงก์อุโมงค์เปลี่ยน ต้องสร้างตัวโหลดใหม่ด้วยเมนู 5)

ลิงก์ถาวร ฟรี (Tailscale Funnel) แทน trycloudflare ที่เปลี่ยนทุกครั้ง
  1. ติดตั้ง Tailscale: https://tailscale.com/download/windows แล้วล็อกอิน (ใช้บัญชี Google ได้)
  2. ดับเบิลคลิก start-funnel.bat (ครั้งเดียวพอ) ถ้าเบราว์เซอร์เด้งให้เปิด Funnel/HTTPS ให้กดอนุญาต
     จะได้ลิงก์ https://ชื่อเครื่อง.xxxx.ts.net ใช้ได้ตลอด รีสตาร์ทคอมก็ยังเป็นลิงก์เดิม (ลิงก์ใหม่อาจใช้เวลาถึง 10 นาทีกว่าจะเข้าได้)
  3. admin.bat เมนู 5 (สร้างตัวโหลดใหม่) และเมนู 6 (ส่งลิงก์ใหม่ให้ลูกค้า) ครั้งสุดท้าย ระบบเจอลิงก์ถาวรเอง ไม่ต้องพิมพ์
  4. (แนะนำ) install-autostart.bat ให้เซิร์ฟเวอร์เปิดเองตอนเปิดคอม
  หลังจากนี้ไม่ต้องเปิด start-tunnel.bat / cloudflared อีก

สำรองข้อมูล (admin.bat เมนู 13)
  เซิร์ฟเวอร์สำรองโฟลเดอร์ data ให้เองตอนเปิด และทุก 6 ชั่วโมง เก็บ 28 ชุดล่าสุด (~7 วัน) ไว้ในโฟลเดอร์ backups
  update.bat ก็สำรองให้ทุกครั้งก่อนอัปเดต / สำรองเองได้ที่เมนู 13 > 1
  กู้ข้อมูล: ปิด start-cloud.bat ก่อน > เมนู 13 > 3 > เลือกชุด (ข้อมูลก่อนกู้ถูกเก็บไว้ให้เป็น before-restore-...)
  แนะนำ: ก๊อปโฟลเดอร์ backups ไปเก็บไว้ที่อื่นเป็นครั้งคราว (แฟลชไดรฟ์/Google Drive) เผื่อฮาร์ดดิสก์เสีย

รีจอยอัตโนมัติ (admin.bat เมนู 12)
  ในเกม: หลุด/โดนเตะแต่หน้าต่างยังอยู่ สคริปต์พากลับเข้าเกมเอง (ปิดได้ที่ AUTO_REJOIN ในสคริปต์)
  นอกเกม: เกมปิด/แครช เซิร์ฟเวอร์เห็นว่าไอดีเงียบเกินเวลาที่ตั้ง แล้วสั่ง Roblox Account Manager (RAM) เปิดไอดีนั้นใหม่
  ตั้งค่าใน RAM ครั้งเดียว: Settings > Developer > เปิด Enable Web Server, ติ๊ก Allow LaunchAccount และ Allow GetAccounts,
    ตั้ง Password (ตัวอักษร/ตัวเลข 6 ตัวขึ้นไป) และแนะนำติ๊ก Every Request Requires Password แล้วปิด-เปิด RAM ใหม่
  แล้วใน admin.bat เมนู 12 > 1 ใส่พอร์ตและรหัสเดียวกับใน RAM > เมนู 12 > 2 ทดสอบ
  ชื่อไอดีใน RAM ต้องตรงกับชื่อผู้ใช้ Roblox (เมนู 12 > 2 จะบอกว่าไอดีไหนไม่มีใน RAM)
  ระยะรอระหว่างรีจอยไอดีเดิม: 5, 10, 20, 40, 60 นาที / เว้น 20 วินาทีระหว่างไอดี / เงียบเกิน 12 ชม. เลิกรีจอย
  ใส่ Discord webhook ไว้ จะได้แจ้งเตือนทุกครั้งที่หลุด/รีจอย/กลับมาออนไลน์ (ใช้ได้แม้ไม่เปิดรีจอย)
  ประวัติอยู่ที่ data\rejoin.log

โหมดเจ้าของรันเอง (ค่าเริ่มต้น): คุณรันสคริปต์ ลูกค้าดูอย่างเดียว
  1. เมนู 5 สร้างสคริปต์ของคุณ (data\scripts\OWNER-SCRIPT.lua) ใช้ตัวเดียวทุกไอดี ใส่ auto-execute ได้ ส่งข้อมูลทุก 5 นาที
  2. เมนู 1 เพิ่มลูกค้า ใส่ชื่อผู้ใช้ Roblox ของไอดีที่เป็นของเขา -> ได้ลิงก์ ส่งลิงก์ให้ลูกค้าทางแชทส่วนตัว
  3. ลูกค้าเปิดลิงก์ เห็นเฉพาะไอดีที่กำหนดให้ หน้าเว็บรีเฟรชเองทุก 3 วินาที
  - เพิ่ม/ย้ายไอดี: เมนู 3 (ไอดีหนึ่งมีเจ้าของได้คนเดียว กำหนดให้คนใหม่ = ย้ายออกจากคนเดิม)
  - เช็คว่าไอดีไหนยังไม่มีเจ้าของ: เมนู 4
  - ที่อยู่เซิร์ฟเวอร์เปลี่ยน (เปิดอุโมงค์ใหม่): เมนู 5 สร้างสคริปต์ใหม่ + เมนู 6 ดูลิงก์ลูกค้าทุกคนด้วยที่อยู่ใหม่ (คีย์ลูกค้าไม่ต้องเปลี่ยน)
  - ไฟล์ data\customers.json เก็บลิงก์ลูกค้าไว้เพื่อแสดงซ้ำได้ อย่าแชร์ไฟล์นี้หรือโฟลเดอร์ data ให้ใคร

โหมดคีย์ลูกค้า: ลูกค้าแต่ละคนได้สคริปต์ของตัวเอง (data\scripts\ชื่อ-id.lua) + ลิงก์
  ไอดีที่รันด้วยสคริปต์ของใคร จะขึ้นในหน้าของคนนั้น (จำกัดจำนวนไอดีสูงสุดได้)
  ลูกค้าที่อยากใช้แอปบนคอม ใช้ "รหัสเปิดใช้งาน" SFA1. ที่แสดงตอนเพิ่มลูกค้า

สลับโหมดแล้ว สคริปต์ของอีกโหมดจะหยุดรับข้อมูลทันที (ข้อมูลเดิมไม่หาย สลับกลับมาก็เห็นเหมือนเดิม)

ลองในเครื่องก่อน (Windows)
  1. ติดตั้ง Node.js (https://nodejs.org) ครั้งเดียว
  2. ดับเบิลคลิก start-cloud.bat  (หน้าต่างดำที่เปิดขึ้นมาคือเซิร์ฟเวอร์ ปิดหน้าต่าง = เซิร์ฟเวอร์หยุด ไม่มีหน้าเว็บให้ดู)
  3. ดับเบิลคลิก admin.bat  เลือก 1 เพิ่มลูกค้า ใส่ที่อยู่เซิร์ฟเวอร์เป็น http://127.0.0.1:8800
  4. ก๊อป "รหัสเปิดใช้งาน" ไปวางในแอป Slayer Fleet ปุ่ม "ดูบนมือถือ" แล้วเปิดลิงก์ที่ได้ในเบราว์เซอร์เครื่องเดียวกัน
  (ทดสอบแบบนี้ใช้ได้เฉพาะในเครื่องเดียวกัน ถ้าจะให้มือถือดูได้ต้องขึ้น VPS ตามด้านล่าง)

ให้มือถือ/เครื่องอื่นดูได้โดยยังไม่ต้องเช่าโดเมน (Cloudflare Quick Tunnel ฟรี ใช้ทดลอง)
  1. ดาวน์โหลด cloudflared สำหรับ Windows จากหน้า releases ของ cloudflare/cloudflared บน GitHub
     เปลี่ยนชื่อเป็น cloudflared.exe แล้ววางในโฟลเดอร์นี้
  2. เปิด start-cloud.bat ค้างไว้ แล้วเปิด start-tunnel.bat อีกหน้าต่าง จะเห็นลิงก์ https://....trycloudflare.com
  3. เปิด admin.bat เพิ่มลูกค้า โดยใส่ลิงก์นั้นเป็นที่อยู่เซิร์ฟเวอร์ ได้รหัสเปิดใช้งานและลิงก์ดูที่ใช้ได้ทั้งมือถือและคอม
  ข้อจำกัด: คอมคุณต้องเปิดทั้งสองหน้าต่างไว้ตลอด / ลิงก์เปลี่ยนทุกครั้งที่ปิดแล้วเปิด start-tunnel.bat ใหม่
  (ลิงก์อยู่ในรหัสเปิดใช้งาน เมื่อลิงก์เปลี่ยน ต้อง "ออกคีย์ใหม่" ข้อ 5 ในเมนู แล้วส่งรหัสใหม่ให้ลูกค้า)
  Cloudflare ระบุว่า Quick Tunnel ไว้ใช้ทดลอง ไม่รับประกันความเสถียร ถ้าจะให้ลูกค้าใช้ประจำควรใช้ลิงก์ถาวร

ติดตั้งจริง (VPS ที่มี Node.js 18+)
  1. อัปโหลดโฟลเดอร์นี้ขึ้นเซิร์ฟเวอร์
  2. ตั้งค่า HTTPS ด้วย reverse proxy เช่น Caddy (ได้ใบรับรองฟรีอัตโนมัติ) ไฟล์ Caddyfile:
         fleet.yourdomain.com {
             reverse_proxy 127.0.0.1:8800
         }
  3. รัน (ควรใช้ systemd หรือ pm2 ให้รันค้างและเริ่มใหม่เอง):
         TRUST_PROXY=1 PUBLIC_URL=https://fleet.yourdomain.com node server.js
     !! TRUST_PROXY=1 สำคัญมากเมื่ออยู่หลัง proxy ไม่งั้นทุกคนจะดูเป็น IP เดียวกัน ตัวกันเดารหัสทำงานผิด
     !! ห้ามเปิดพอร์ต 8800 ออกอินเทอร์เน็ตตรงๆ ให้ผ่าน Caddy เท่านั้น (เซิร์ฟเวอร์ฟัง 127.0.0.1 อยู่แล้ว)

จัดการลูกค้า (ไม่ต้องหยุดเซิร์ฟเวอร์) ง่ายสุดคือดับเบิลคลิก admin.bat (Linux: ./admin.sh) หรือใช้คำสั่งตรง:
  node admin.js add "ชื่อลูกค้า" --days 30 --max 50 --url https://fleet.yourdomain.com
  node admin.js list
  node admin.js renew <id> --days 30
  node admin.js revoke <id>   /   unrevoke <id>
  node admin.js rotate <id>   (ออกคีย์ใหม่ ของเก่าใช้ไม่ได้ทันที)
  node admin.js remove <id>   (ลบลูกค้า ข้อมูลของเขาถูกลบตามอัตโนมัติ)
  หมดอายุหรือถูกระงับ -> ทั้งส่งและดูข้อมูลไม่ได้ทันที นี่คือกลไกไลเซนส์ของคุณ

ขีดจำกัดที่ตั้งไว้
  ส่งข้อมูล 120 ครั้ง/นาที/ลูกค้า, ดู 300 ครั้ง/นาที, ข้อมูลต่อคำขอไม่เกิน 512KB, 100 ไอดีต่อคำขอ,
  ไอดีสูงสุดต่อลูกค้าตาม --max (ค่าเริ่มต้น 50), เก็บประวัติ 2000 จุดต่อไอดี

ข้อควรรู้
  - เก็บข้อมูลเป็นไฟล์ JSON (data/data.json) เหมาะกับหลักสิบถึงหลักร้อยลูกค้า ถ้าโตกว่านั้นควรย้ายเป็นฐานข้อมูลจริง
  - สำรองโฟลเดอร์ data/ เป็นประจำ (customers.json = สิทธิ์ของลูกค้า สำคัญที่สุด)
  - ลิงก์ดูเก็บในส่วน # ของ URL เบราว์เซอร์ไม่ส่งส่วนนี้ให้เซิร์ฟเวอร์ ไม่ติด log และไม่รั่วทาง Referer
  - ข้อมูลที่เก็บ: ชื่อไอดี เลเวล Wen สถิติ ของในคลัง (ชื่อไอดีและ UserId ถือเป็นข้อมูลส่วนบุคคล ควรมีนโยบายความเป็นส่วนตัว
    และช่องทางให้ลูกค้าขอลบข้อมูล: ใช้ admin.js remove)
  - แก้ UI ในแอปแล้ว ให้ก๊อปไฟล์ใน slayer-fleet-app/renderer/ ทับ public/ ที่นี่ด้วย เพื่อให้หน้ามือถือหน้าตาเหมือนกัน
